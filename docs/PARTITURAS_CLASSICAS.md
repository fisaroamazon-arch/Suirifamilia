# Partituras clássicas do piano

O repertório usa arranjos jogáveis para o teclado compacto. A faixa de aprendizado escolhe uma linha principal, e a faixa de dueto usa uma seleção do acompanhamento. As sequências preservam as alturas das notas escolhidas e a duração das edições digitais, com a pulsação e os silêncios. Os títulos identificam os movimentos ou as cenas quando fazem parte de uma obra maior.

As adaptações de obras sob [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) permanecem sob a mesma licença. Elas incluem a redução das vozes e a conversão para o formato do jogo. O restante da tabela indica a condição de cada edição de origem.
